# 비밀번호 불일치 잠금은 글 단위로 센다

비밀번호 무차별 대입을 막기 위해, 한 글에 비밀번호 불일치가 연속 10회 쌓이면 그 글의 수정·삭제를 5분간 누구에게도 허용하지 않는다. 실패 횟수는 시도한 사람(IP)과 무관하게 글 단위로 세며, 글 테이블에 `failed_attempts`, `locked_until` 두 칸으로 저장한다.

## Consequences

- 제3자가 일부러 틀린 비밀번호를 10번 넣어 작성자 본인을 5분간 막을 수 있다. 잠금이 짧아 피해가 작고, IP를 저장하지 않아도 되므로 이 약점을 받아들였다.
- IP 기준으로 바꾸려면 별도 시도 기록 테이블이 필요하다.
